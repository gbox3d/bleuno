# type_m 전원 설계 검토 — 2026-11-01

대상은 저장된 KiCad `type_m_v1_1.kicad_sch/.kicad_pcb`입니다. 연결된 실물·케이블·모듈 내부 회로를 검사한 결과로 해석하지 않습니다. 검토 중 설계 파일은 변경하지 않았습니다.

## 확인된 설계 문제

1. **배터리 극성 안내의 좌우 순서가 실제 패드와 반대입니다.** 전면에서 보았을 때 J1 왼쪽 원형 패드 2는 GND(−), 오른쪽 사각 패드 1은 VCC(+)입니다. 그런데 전면 실크는 `BAT + -`입니다. J1의 회전은 0°이며 텍스트도 미러되지 않았습니다. 하나의 텍스트가 패드 중앙에 정렬된 표시는 아니지만, 두 극성 기호의 좌우 순서는 실제 배선과 반대이므로 잘못된 연결을 유도할 수 있습니다. [KiCad 원본 SVG 확대](battery-polarity-review.png)
2. **전원 스위치가 부하 전원과 직렬로 연결되지 않았습니다.** 배터리 J1.1은 VCC 부하에 직접 연결됩니다. J2.2도 VCC이고 J2.3의 VIN은 다른 구리에 연결되지 않은 단독 패드입니다. 이 구조에서는 J2로 배터리 전원을 차단할 수 없습니다.
3. **배터리 커넥터 J1의 회로도 값이 `MT1`입니다.** PCB의 BAT 커넥터와 동일한 부품인데 모터 출력처럼 표시됩니다. 이 오표기가 전기 연결 자체를 바꾸는 것은 아닙니다.

## 실제 연결과 판정 범위

| 대상 | KiCad에서 확인한 연결 |
|---|---|
| 배터리 + | J1.1 → VCC → U1.8, U2.9, J5.1, J6.1, J2.2, R1.1 |
| 배터리 − | J1.2 → GND 트랙·채움 영역 → U1.7, U2.10, J5.3, J6.3, J7.3, R2.1 |
| 스위치 입력으로 보이는 VIN | J2.3 하나뿐; 다른 트랙·패드·채움 영역과 접촉 없음 |

트랙·패드·채움 영역의 실제 구리 접촉과 별도 KiCad 연결 계산으로 배터리에서 U1까지 경로가 있음을 확인했습니다. 따라서 **KiCad 저장 설계에서 BAT–U1 전원 배선이 끊겼다는 증거는 없습니다.** 이것이 실물 동작이나 극성 표기가 올바르다는 뜻은 아닙니다. DRC가 통과해도 실크 의미와 전원 스위치의 기능적 연결 오류를 검출하지 못할 수 있습니다.

회로도에서 U1.8은 `+5V`, U1.7은 `GND`, U1.6은 `+3V3`이며 PCB 네트는 각각 VCC/GND/3.3V입니다. U1 풋프린트에는 이 세 전원 핀을 식별할 실제 모듈 핀 실크가 없고, 모듈 내부 전원 회로도 포함되어 있지 않습니다. 따라서 KiCad만으로 실제 SuperMini Plus의 내부 전압 조절·USB 역류 방지 특성을 확정하지 않았습니다.

사용자는 USB로 부팅되고 배터리로는 부팅되지 않는다고 보고했으며, 처음 3.7V 배터리라고 설명한 뒤 4.9V가 측정된다고 알려 주었습니다. 측정 위치와 전원 모듈 포함 여부는 확인되지 않았습니다. 이를 근거로 배터리 전압 부족·실제 역극성·부품 손상을 확정하지 않습니다. 사용자에게 추가 측정이나 연결 변경을 요청하지 않고 설계 검토만 진행했습니다.

## 수정 대상

- BAT 극성 표시는 각 패드의 실제 극성에 맞게 따로 배치하여 좌우 오해를 없앱니다. 표시만 바꿀지 배선/커넥터 규약도 바꿀지는 전원부 수정 시 함께 결정해야 합니다.
- 배터리 입력 네트와 스위치 뒤 부하 전원 네트를 분리하여 스위치가 실제 직렬 경로가 되도록 합니다.
- J1의 회로도 명칭을 BAT로 바로잡습니다.
- 3.7V라는 명목값만으로 승압 회로를 먼저 확정하지 않습니다. 현재 KiCad에 없는 모듈 내부 전원 특성과 부하 조건을 구분합니다.

원시 연결 증거는 [power-audit.json](power-audit.json)에 있습니다.
