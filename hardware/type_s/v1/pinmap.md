# BLEuno type_s v1 원본 핀맵

## 기준과 범위

이 문서는 EasyEDA 프로젝트 `ZeroFactorySensorBoard`의 `Board_DHT` 회로도·PCB에서 확인한 연결을 기록한다.
모델명은 `type_s`, 하드웨어 리비전은 `v1`이다. 원본은 [source 안내](source/README.md), 이전 상태와 검사 결과는 [검증 안내](validation/README.md)를 참조한다.
원본의 실제 배치 부품은 ESP32-C3 Supermini 모듈 1개, 저항 5개, 커넥터 9개다. **DHT·CDS·DS18B20은 커넥터 표기이며 해당 센서가 보드에 실장되어 있다는 뜻이 아니다.**
회로도와 PCB의 15개 부품·52개 패드에서 연결 네트가 일치함을 확인했다. 이는 전압·부품값·실물 동작 또는 제작 적합성을 보증하지 않는다.

원본에는 같은 참조명 `10K`가 반복되므로 아래 표는 원본 표기와 회로도 객체 ID로 구분하며 이전용 KiCad 참조를 함께 적었다. 모듈의 핀 번호는 **Supermini 모듈 패드 번호**이며 ESP32-C3 칩 패키지의 물리 핀 번호가 아니다.

## 저항과 전원

| 원본 표기 | KiCad 참조 | 회로도 ID / PCB ID | 회로도 값 | 패드 1 → 패드 2 | 역할 |
|---|---|---|---|---|---|
| `10K` | R3 | `e2958` / `e211` | 10kΩ | 3.3V → SENSOR1 | DHT 신호 풀업 |
| `10K` | R4 | `e3004` / `e207` | 10kΩ | 3.3V → SENSOR2 | CDS 신호 풀업 |
| `4.7k` | R5 | `e3064` / `e203` | 4.7kΩ | SENSOR3 → 3.3V | DS18B20 신호 풀업 |
| `10K` | R1 | `e3937` / `e227` | 220kΩ | 5V → BATCHK | 분압 상단, 원본 값 불일치 |
| `10K` | R2 | `e3961` / `e231` | 220kΩ | BATCHK → GND | 분압 하단, 원본 값 불일치 |

분압 저항 2개의 회로도 `Value`는 각각 `220kΩ`지만 원본 PCB에는 값 재정의가 없어 공통 라이브러리의 `10kΩ`를 상속하며 표기도 `10K`다.
두 경우 모두 분압비는 1/2이나 전류·입력 임피던스는 다르다. 제조 BOM과 실제 부품값은 설계자 확인이 필요하며 이 문서에서 임의로 결정하지 않는다.
KiCad R1/R2에도 이 원본 값 차이를 보존했다. R5의 표시는 원본 `Name`인 `R`을 유지하며, 양쪽 원본 `Value`인 `4.7kΩ`는 숨김 속성 `Source Schematic Value`·`Source PCB Value`에 보존했다.
[이전 참조 대응표](validation/normalization-report.json)에서 원본 ID와 KiCad 참조·속성을 확인할 수 있다.

전원 경로는 `BAT 1번(VCC) → On Off 1번`, `On Off 2번(5V) → 모듈 5V / D1~D3 전원 / 분압 상단`이다.
원본의 `On Off`는 헤더이며 별도 스위치 부품이 실장된 것이 아니다. 1번과 2번을 외부에서 연결하는 방식과 공급 전압은 실물 기준으로 확인해야 한다.
`5V`는 네트 이름이다. 실제 배치된 15개 부품에는 별도 레귤레이터나 레벨 변환기가 없으며 모듈 내부 회로는 이 원본으로 검증하지 않았다.
D1~D3의 전원 핀은 `5V`지만 신호 핀은 GPIO6/7/10에 직접 연결된다. 이 사실을 신호의 5V 허용 근거로 사용하지 않는다.
BATCHK는 BAT의 VCC가 아닌 전원 헤더 뒤 `5V`를 분압한다.

## 교재·펌웨어 적용 전 확인

- 기존 수업용 `ledpin=[4,3,1,0]`은 type_s v1에서 SENSOR2·SENSOR1·A1·BATCHK를 출력으로 사용하므로 그대로 적용하지 않는다.
- 기존 `dht11pin=7`은 DHT 헤더가 아닌 D2에 해당한다. 원본 DHT 신호는 GPIO3이지만, 센서 종류·외부 결선·전압·풀업·실물 동작을 확인하기 전에는 수업의 확정 설정으로 사용하지 않는다.
- 현재 펌웨어의 센서 명령은 `dht11`이다. CDS·DS18B20·BATCHK용 읽기 명령은 구현되어 있지 않다. 커넥터가 있다는 이유로 앱이나 펌웨어가 해당 기능을 지원한다고 가정하지 않는다.
- MCU의 GPIO2/8/9/20/21과 `On Off` 3번은 원본에서 외부 배선이 없다. type_m v1의 SEN1·VIN 미연결 설명을 이 보드에 적용하지 않는다.
- 센서·부하 연결, 배터리 공급 조건, 분압 저항값과 실제 모듈 핀을 확인한 후 모델별 펌웨어 설정과 Android 실기 시험을 별도로 진행한다. 현재 회로 수정·펌웨어 변경·실물 검증은 하지 않았다.
